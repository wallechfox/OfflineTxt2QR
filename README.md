# OfflineTxt2QR - 离线文本转二维码生成器

一个完全离线的、完美支持中文的文本转二维码工具。无需网络连接，所有数据处理均在浏览器本地完成。Convert any text to QR code completely offline. Perfect Chinese support, no internet required, all processing done locally in your browser.

## ✨ 核心特性

- ✅ **完全离线运行** - 无需任何网络连接，保护您的数据隐私
- ✅ **完美中文支持** - 原生UTF-8编码，无乱码无URL编码问题
- ✅ **长文本优化** - 支持生成1000+字的中文二维码，智能容错调整
- ✅ **四种容错级别** - L/M/Q/H 多种纠错等级可选
- ✅ **响应式设计** - 适配桌面、平板和手机浏览器
- ✅ **数据零上传** - 所有内容仅在本机处理，绝对安全

## 📱 使用方法

### 三步生成二维码
1. **输入文本** - 在左侧文本框输入任意内容（支持中文、英文、特殊字符）
2. **调整设置** - 选择合适的尺寸和容错级别
3. **点击生成** - 系统会自动优化并生成二维码

### 设置说明
- **尺寸调整** (100-1200px)：支持滑块和数字输入
- **容错级别**：
  - **L (7%)** - 最大容量，适合长文本
  - **M (15%)** - 平衡容量与容错
  - **Q (25%)** - 较高容错能力
  - **H (30%)** - 最强纠错，适合打印应用
- **自动适应** - 智能根据文本长度优化尺寸

### 快捷键
- `Ctrl + Enter` - 快速生成二维码
- `Esc` - 重置输入框

## 🔍 常见问题

### Q: 为什么我的长文本无法生成？
**A**: 请尝试：
1. 选择更低的容错级别（L或M）
2. 适当减少文本长度
3. 系统会自动提供解决方案

### Q: 扫描后出现乱码？
**A**: 确保使用支持中文的扫码工具，推荐：
- 支付宝内置扫码
- 专业的二维码扫描器
- 最新版手机相机扫码

### Q: 如何实现完全离线？
**A**: 只需下载完整项目文件，包括：
1. `OfflineTxt2QR.html`
2. `qrcode.min.js`
